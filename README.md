# Sales Data Analysis Dashboard – Excel

## Project Overview
Created an interactive Excel dashboard to analyse sales data and understand business performance. The project focuses on sales trends, product performance, key performance indicators (KPIs) and top-performing categories.

## Tools Used
Microsoft Excel.

## Analysis Performed
Organised and analysed sales data, calculated important KPIs and created charts to present sales performance and business insights.

## Key Findings
The dashboard highlights sales performance, top-performing products and important business metrics.

## Conclusion
This project demonstrates how Excel can be used to analyse sales data and present meaningful insights through an interactive dashboard.
